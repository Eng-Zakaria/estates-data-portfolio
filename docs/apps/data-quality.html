Data quality framework

One YAML file per dataset compiles to Great Expectations or DuckDB, then scores, trends and alerts — measured at 100% recall on deterministic planted defects.
Synthetic data. Synthetic data for portfolio demonstration. No real university, building, person or performance data is shown or implied.

Checks are declared once in YAML and compiled to either a Great Expectations suite or a DuckDB SQL check, depending on whether the rule is row-level or statistical. Scoring is weighted (error = 3, warn = 2, info = 1) and a drop of more than 5 points against the trailing mean raises an alert.
