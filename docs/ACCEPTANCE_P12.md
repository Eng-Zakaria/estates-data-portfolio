## 3. Loader is idempotent; rejects carry reasons

```
$ rm -rf data/cobie/handover && python projects/p12-cobie-validator/src/cli.py load data/cobie/valid.xlsx --out data/cobie/handover
inserted=8 updated=0 unchanged=0 rejected=0
$ python projects/p12-cobie-validator/src/cli.py load data/cobie/valid.xlsx --out data/cobie/handover
inserted=0 updated=0 unchanged=8 rejected=0
$ python projects/p12-cobie-validator/src/cli.py load data/cobie/corrupted.xlsx --out data/cobie/handover_bad
inserted=3 updated=0 unchanged=0 rejected=6
```

`handover_bad/quarantine.csv` holds one reason string per rejected row
(unknown TypeName/Space, missing SerialNumber, duplicate serial).
`--dry-run` prints the same diff and writes nothing (tested).

## 4. AIR change needs no code change

`tests/test_cobie.py::test_air_edit_changes_results_without_code_change` drops one
rule from the loaded AIR YAML and asserts the warning count falls — passes.
