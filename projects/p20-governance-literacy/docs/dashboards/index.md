## Four habits that stop most mistakes

1. **Check the date first.** Every page has a refresh time or an as-of date. If it is old, the number is history.
2. **Read the definition, not just the number. Each metric has one, with a list of what it cannot tell you.
3. **Do not add totals from different filters.** Two buildings filtered separately and then added up is not the estate total.
4. **Say "as at" when you report.** "Overdue as at 31 March" is a fact. "Overdue" on its own is not.

## The data is synthetic

Every report in this portfolio runs on generated data. The buildings, rooms, jobs, meters and sensors are made up. Use the reports to learn how to read them, not to make claims about a real estate.

## If something looks wrong

1. Write down the report, the page, the filter you used and the number.
2. Check the [data quality scorecard](data-quality-scorecard.md) for a failing check that might explain it.
3. If the numbers add up but the answer looks odd, read the "common misreadings" section on that page. It is usually there.
4. Still wrong? Send it to the steward named on the page. One screen and the filter gets it fixed faster than a description.
