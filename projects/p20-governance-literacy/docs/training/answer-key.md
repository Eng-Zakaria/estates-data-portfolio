# Answer key

Mark it in pairs, out loud. The wrong answers are more useful than the right ones: they show which misreading is live in your team.

| # | Answer | Look for |
|---|---|---|
| 1 | Booking frequency multiplied by average occupancy. It is a product, not a time-weighted average, so a single large booking can score like daily half-full use. | "Frequency times occupancy" |
| 2 | Blank, not zero. Zero says the room was measured and used for no hours; blank says we have no bookings to measure. | Distinguishing no data from no use |
| 3 | A sum of two filtered subsets, which is not the estate total and can double count if the filters overlap. | "Filters change every number" |
| 4 | The second one. Overdue is measured against an as-of date, and the number changes as that date moves. | The date is part of the fact |
| 5 | Gross internal area is larger. Energy per square metre uses gross internal area, matching the whole envelope. Net internal area is for space per person. | Two areas, two uses |
| 6 | That the checks that exist passed. It says nothing about a definition being wrong, and nothing about a field nobody checks. | "Measures the checks we wrote" |
| 7 | It appears as no record, often with a green or neutral cell. The risk is that absence of a record reads as compliance. | "Green can mean nothing recorded" |
| 8 | The green tariff is not credited. Location-based accounting uses the grid average factor, so the number does not fall because of the tariff. A market-based figure would need contractual evidence. | Location-based ignores instruments |
| 9 | Only the accountable owner for that domain, on the steward's advice. The change is logged with its reason and impact. | Owner decides, not analytics |
| 10 | Write down the report, page, filter and number, then check the data quality scorecard for a failing check. If the numbers add up but look odd, read the "common misreadings" section on that dashboard's guide page. | Evidence before opinion |
| 11 | Because uncovered events are excluded rather than counted as no-shows. Adding sensors moves events out of the "uncovered" bucket, so the ratio changes for a data reason, not a behaviour reason. | Denominator changes |
| 12 | The two figures are not comparable, and the paper invites the reader to compare them. Different denominators on the same phrase is how a committee ends up with two truths and one decision. | Definition ambiguity |

## Scoring

| Score | What to do |
|---|---|
| 9 or more | they can teach it. Ask them to run the 10-minute demo. |
| 6 to 8 | solid. Point them at the dashboard guide for their report. |
| 4 or 5 | worth another session; run the workshop again with a different report. |
| below 4 | start with the 10-minute demo and the glossary, not with the dashboards. |

Do not use the score in any performance process. The point is to find which misreading to cover next time.
